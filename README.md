# Best Fit Showdown — Unit 3 Stats Test Review

A review game for one student or a group of 2–3 sharing one device, built for the Stats B Unit 3 test
(scatterplots, correlation, causation vs. lurking variables, explanatory/response variables,
segmented bar graphs, slope and intercept, residuals and predictions). Designed for about 60 minutes.

## How to open it
- Open `index.html` in any web browser, or
- Turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`, folder `/`) and share the link with students.

## How it plays
- Six topic columns, each with 1-, 2- and 3-point tiles. A new question is generated every time a tile is picked.
- Students explain their reasoning out loud before answering; a partner can steal a missed question for half the points.
- Written-answer cards are scored by partners using an on-screen checklist.
- Two Team Rounds (at the 1/3 and 2/3 marks) have everyone work a full test-style problem on paper, then check it against a key.
- The results screen shows which topics the group should review.
- **Solo mode:** no steals, students score their own written answers, and Team Rounds become Challenge Rounds. The goal is to score in all six categories and beat 40 points.

## Completion codes
At the end, the results screen shows a code like `BF-1P05-0503-1292-FZFZ`. Students write it down with their names.
To check one, open the game, expand **"Teacher: check a completion code"** on the start screen, and enter the code and names.
It shows active minutes played, the date, turns, questions answered, percent correct and Team Rounds finished.
